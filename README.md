# Python Mini Apps

A responsive, dark-themed portfolio project with interactive mini tools and Python code examples.

## Features
- Quick calculator
- Number guessing game
- Password generator
- Celsius/Fahrenheit converter
- To-do list (session-only; tasks are not saved)
- Python snippets: Hello World, Even/Odd, Factorial
- Responsive layout for desktop and mobile

## Run in VS Code
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or install the **Live Server** extension and choose **Open with Live Server**.
4. No build step or dependencies are required.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `python-mini-apps`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish and copy the URL shown in Settings → Pages.

## Note
The interactive tools run in JavaScript in the browser. The Python snippets are examples to copy and run in Python IDLE or VS Code; this project does not execute Python code in the browser.
